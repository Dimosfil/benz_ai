# Сообщения об отсутствии бензина

В открытой карточке АЗС выберите АИ‑92 и/или АИ‑95, которых сейчас нет,
подтвердите «Я проверил на этой АЗС сейчас» и нажмите «Отправить сообщение».
Форма сообщает о сохранении или ошибке. При ошибке отправку можно повторить.
Время проверки назначает сервер при отправке; задним числом отчёт не подаётся.

Отмеченные марки становятся красными («Вероятно нет»). Карточка показывает
«Сообщение посетителя», время МСК и срок действия. Карта, таблица и счётчики
обновляются без запроса источников. Дизель, газ и другие марки сохраняют
отдельные статусы. При противоречии по видам топлива общий маркер жёлтый;
для оценки бензина выберите соответствующие марки в фильтре.

Отчёт действует менее 60 минут от серверного времени отправки. Старые данные
и банковские операции, включая более новые оплаты, его не отменяют:
оплата не подтверждает отпуск конкретной марки. Более новое прямое
подтверждение наличия этой марки от небанковского источника снимает приоритет
отчёта только для этой марки. Для Яндекса требуются минимум два подтверждения.
После часа возвращается обычный расчёт по источникам. Возраст пересчитывается
клиентом каждые 30 секунд и при возвращении на страницу; обновление страницы
получает актуальный расчёт с сервера. Цены отчёт не меняет.

Сообщения публичные и не проверяются оператором; авторизация посетителя пока
не предусмотрена. Они показываются как вероятностный сигнал с явным указанием
происхождения. При повторной отправке обновляются только отмеченные марки.
Статус наличия и остановка обслуживания (например, слив топлива) остаются
разными фактами. Наличие бензовоза не определяется.

## Хранение и запуск

По умолчанию файл — `data/station-reports/reports.json`, не включённый в Git.
`STATION_REPORTS_DATA_FILE` позволяет задать другой путь. Один серверный
процесс владеет файлом, записи сериализуются и заменяются атомарно. Сохраняются
только идентификаторы публичной АЗС, отмеченные марки, статус и время;
идентификаторы посетителей и свободный текст не сохраняются.

Перезапуск сохраняет ещё действующие отчёты. В Compose используется отдельный
volume `station-reports`; образ создаёт каталог с правами пользователя `node`.
Для обновления локального контейнера используйте `docker compose up -d --build`.
Не удаляйте volume для обычного обновления. Другие посетители получают отчёт
при следующей загрузке территории; отдельного канала push-обновлений нет.

В памяти доступны идентификаторы до 5000 станций, на диске — до 1000 действующих
отчётов. При превышении предела вытесняются старейшие записи. Истёкшие отчёты
игнорируются при загрузке и удаляются из файла при следующем сохранении.
Неверный формат или недоступный файл отключает отправку, сообщает причину в
карточке и оставляет основной поиск работающим. Файл не перезаписывается молча.

## API

`POST /api/station-reports`, `Content-Type: application/json; charset=utf-8`:

```json
{
  "sourceRefs": [{ "source": "tbank", "externalId": "station-id-from-response" }],
  "fuels": ["92", "95"],
  "checkedOnSite": true
}
```

Сначала загрузите станцию через поиск или карту. Идентификаторы должны
соответствовать известной серверу АЗС. Ответ `201` содержит `{ "station": ... }`,
включая `fuelReports`, `baseAvailability` и пересчитанные статусы. Поля добавлены
к существующему формату; банковские и провайдерские сигналы не переписываются.

Ошибки: `400` — неверные данные, `404` — станция неизвестна, `405` — другой
метод, `403` — другой origin, `413` — тело больше 8 КиБ, `415` — другой тип
содержимого, `429` — превышен лимит, `503` — хранилище недоступно. Используется
отдельная корзина лимита отправок на IP с настройками `REQUEST_RATE_REFRESHES`
и `REQUEST_RATE_WINDOW_MS` (по умолчанию три сообщения за минуту).

## Проверки

`npm test` включает сценарии приоритета, независимости дизеля, истечения срока,
более новых подтверждений, конкурирующих снимков карты, сохранения после
перезапуска, алиасов и соседних АЗС, ошибок формы, валидации HTTP и лимита.
Проверки используют синтетические данные и отдельные временные хранилища;
реальные отчёты и внешние топливные источники не изменяются.
