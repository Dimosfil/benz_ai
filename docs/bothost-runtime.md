# Публичный сервер BotHost

Действующее приложение: https://daimnebenz.bothost.tech/ (адрес предоставлен
пользователем 16 сентября 2026). Версия проверяется через `GET /api/health`,
точечные цены — через `GET /api/station-prices?yandexOrgId=<ID>`.

Исходники: `https://github.com/Dimosfil/benz_ai`, ветка `main`.
Артефакт локальной проверки: `docker compose build`, образ `benz-ai:local`.
Push подтверждает обновление исходников, но не обновление публичного приложения.
Способ запуска пересборки BotHost и доступ к его панели/API пока не настроены
в проекте. После публикации обязательно сверять публичную версию и ответ цен.

Сохранённый ранее шлюз `sub_domen_hub` не является подтверждённым способом
обновления BotHost: его реестр не содержит активного проекта `benz_ai`.

## Диагностика цен

На версии 0.1.41 публичный API отдавал пустые цены, хотя локальный запрос к тем же
карточкам Яндекса их получал. Исходный ответ Яндекса с BotHost пока не доступен;
конкретная причина различия не установлена.

Версия 0.1.42 читает структурированный `fuelInfo` с проверкой ID и отличает
нераспознанный ответ от явно пустого ценового блока. Ошибки содержат код причины
и безопасные признаки ответа, но не исходный HTML. Пустые ответы не кэшируются.
Для проверки используются публичные карточки `159448537853` (Юкон, Отрадное),
`38745431337` (Газпром, Бабяково) и `1163758777` (Лукойл, Отрадное).
Положительный локальный результат не доказывает работоспособность на BotHost.

25 сентября 2026 на публичной версии 0.1.45 подтверждено:
`38745431337` возвращает 503 `YANDEX_PRICES_UNVERIFIED`, upstreamStatus=200,
stateFound=true, cardMatched=true, fuelInfoFound=false. В локальном ответе
той же страницы `fuelInfo` есть. Дополнительно у станции без данных T-Bank
может отсутствовать `yandexOrgId`, поэтому прежний клиент вообще не запускал
точечную проверку цен.

Исправление добавляет поиск по координатам и названию без зависимости от T-Bank
и резервное чтение поискового результата, если страница организации не содержит
цен. Контрольный запрос без ID: `/api/station-prices?lat=51.6927308&lon=39.3768949&name=Газпром`.
Локально он определяет `38745431337` и получает АИ-92=65.25, АИ-95=71.75,
АИ-100=97.2, ДТ=77.1 RUB (дата источника 24 сентября 2026 по Москве).
Это контрольные данные проверки, а не значения для подстановки в приложение.
После пересборки BotHost этот запрос нужно проверить с публичного адреса;
до этого работоспособность исправления на хостинге не подтверждена.
