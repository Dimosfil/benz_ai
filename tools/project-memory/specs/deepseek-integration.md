# Контракт интеграции LLM

## Назначение

В Benz AI используется компактный серверный LLM-транспорт. Основной релизный
режим — локальный LM Studio с Qwen; OpenAI-совместимый DeepSeek остаётся
поддерживаемым резервным режимом.

Адаптер используется как первичный нормализатор пользовательского названия
населённого пункта или административной территории перед геокодированием. Он
исправляет только поисковую формулировку; результат модели
обязательно повторно проверяется геокодером и не подменяет данные источников о
наличии топлива или ценах.

## Контракт

- Точка входа: `createDeepSeekProvider()` в `providers/deepseek.js` (имя
  сохранено для обратной совместимости).
- В режиме `LLM_API_MODE=lmstudio`: `POST <LLM_BASE_URL>/api/v1/chat`, без
  Bearer-токена при `LLM_ALLOW_UNAUTHENTICATED=1`, с `reasoning: "off"`.
- В режиме `openai-compatible`: `POST <LLM_BASE_URL>/chat/completions` с
  необязательным серверным Bearer-токеном.
- Модель задаётся `LLM_MODEL`; значения `DEEPSEEK_*` используются только как
  совместимый fallback при отсутствии соответствующего `LLM_*`.
- Лимит ответа нормализатора задаётся `LLM_NORMALIZER_MAX_TOKENS` (по умолчанию
  `512`).
- Вход: `prompt` либо непустой массив `messages`; дополнительно поддерживаются
  `temperature`, `maxTokens` и `json`.
- Выход: `{ provider, model, output, raw }`; пустой текстовый ответ считается
  ошибкой контракта.
- HTTP-ошибка и таймаут завершают только вызов LLM. Адаптер не изменяет
  данные АЗС и не подменяет фактические сигналы наличия топлива выводом модели.

## Инварианты безопасности

- API-ключ не передаётся в браузер, ответы API, логи или project memory.
- Конфигурация хранит только имя переменной окружения и безопасные значения по
  умолчанию.
- Вызов выполняется только в рамках пользовательского поиска территории. При
  отсутствии настройки, ошибке или некорректном JSON поиск продолжает работу с
  исходной формулировкой.

## Источник и доказательства

- Внешний источник: `D:\AI\llm_providers`.
- Изучены: `README.md`, `package.json`, `src/config.mjs`,
  `src/contracts.mjs`, `src/providerRegistry.mjs`,
  `src/providers/deepseek/index.mjs`,
  `src/providers/openai-compatible/index.mjs` и соответствующие provider tests.
- Перенесённый контракт: OpenAI-совместимое тело запроса, Bearer-аутентификация,
  значения DeepSeek по умолчанию, проверка HTTP-ответа и извлечение текстового
  результата.
- Локальная адаптация: стандартный таймаут Benz AI и отсутствие общей
  мультипровайдерной абстракции.

## Проверка

`npm test` должен подтверждать оба API-режима, отключение reasoning для LM
Studio, серверную авторизацию, извлечение ответа и состояние конфигурации.
