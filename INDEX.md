# Project Instruction Index

- `AGENTS.md`: project entrypoint and task routing.
- `COMMANDS.md`: compact index of `gi` chat commands.
- `BOOTSTRAP.md`: instruction-kit bootstrap guidance.
- `config/gi-command-routes.json`: command aliases and mandatory context.
- `config/gi-context-budgets.json`: context size limits.
- `patterns/GI_COMMAND_CONTRACTS.md`: detailed command contracts.
- `patterns/GIT_WORKFLOW.md`: Git finish rules.
- `patterns/PROJECT_MEMORY_SPECIFICATIONS.md`: specification status and indexing.
- `patterns/MODULAR_SERVICE_ENGINEERING.md`: module ownership and integration.
- `templates/SYSTEM_MAP.template.md`, `templates/MODULE_PASSPORT.template.md`,
  `templates/MODULE_CONTRACT.template.md`: modular-system contract templates.
- `templates/PROJECT_TESTING.template.md`: optional local test scenario scaffold.
- `patterns/AGENTS_RUNTIME/`: focused runtime rules by subject. Modules
  `07-startup.md` and `07-scope-and-evidence.md` cover startup and scope;
  `08-config-service.md`, `08-task-manager.md`, and `08-sprint.md` cover
  service and task workflows; `09-*.md` covers individual operation families.
  The combined `07-startup-and-scope.md`,
  `08-config-service-and-task-manager.md`, and
  `09-project-operation-commands.md` are compatibility indexes only.
- `tools/project-memory/`: implementation-driving project contracts.
- `tools/AGENT_RUNBOOK.md`: local operating commands.
